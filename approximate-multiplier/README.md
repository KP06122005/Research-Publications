# Area Efficient Approximate Multiplier Based on Novel 4:2 Compressors and Error Correction Logic

## Publication

- **Journal:** Scientific Reports
- **DOI:** https://doi.org/10.1038/s41598-025-31282-w
- **Official publication:** https://doi.org/10.1038/s41598-025-31282-w
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0), as indicated in the published PDF.

## Overview

This work investigates an area-efficient approximate multiplier architecture using novel 4:2 compressors and error-correction logic. It explores the trade-off between hardware efficiency and numerical accuracy in approximate multiplication.

## Research focus

- Approximate arithmetic hardware
- 4:2 compressor design
- Error-correction logic
- Hardware area and accuracy trade-offs
