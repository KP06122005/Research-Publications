# RTL Design

This folder contains the Verilog RTL source files for the approximate multiplier.


Approx_8bit.v      ----> Proposed Design that uses truncated logic (AXM2). 
Approx_8bit_ORed.v ----> Proposed Design that uses ORed logic (AXM4). (Refer Publication) 

Other Files are used for direct hardware comparison against our proposed designs.
